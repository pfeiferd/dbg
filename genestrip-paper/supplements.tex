    \section{The dust function $d$}\label{dust function}
We designed a simple dust function $d(s)$ that allows for recognizing and potentially excluding highly repetitive $k$-mers $s$ based on the following rationale:
\begin{enumerate}
	\item Simple repeats like \texttt{TTTTTT}, repeating pairs like \texttt{ATATAT} and repeating triplets like \texttt{ATCATC} should be recognized. (Triplets also form the basis of the approach in \cite{doi:10.1089/cmb.2006.13.1028}.)
	\item The function should be based on the number of times a single base, a pair or a triplet is repeated. E.g. \texttt{AT} is repeated twice in \texttt{ATATAT} and \texttt{ATC} is repeated once in \texttt{ATCATC}. 
	\item A repeat's contribution to $d$ should grow more than linearly with the repeat's length. E.g., \texttt{AAAACA} should obtain at least the $d$-value of \texttt{AACAAA} (or more). 
	\item $d(s)$ should be computable in $O(|s|)$ and should lend itself for streaming computation. I.e., if $d(s) = d(s_1 \ldots s_k)$ is known, then $d(s') = d(s_2 \ldots s_k s'_{k+1})$ should be computable in constant time.
	\item $d$ should be symmetrical. This is because a $k$-mer and its reverse complement should obtain the same dust value \citep{doi:10.1089/cmb.2006.13.1028}.
\end{enumerate}

To specify the dust function $d$, we first define the \emph{skip-$c$-repeat length} at position $i$ in a string $s$ where  $1 \leq i \leq |s|$ and $c \geq 0$:    
\[srl_c(s, i) = \max \{ r\ |\ i + r - 1 \leq |s| - c - 1 \wedge \bigwedge_{j = i}^{i + r - 1} s_j = s_{j + c + 1} \}\]
E.g., two skip-$1$-repeat lenghts for $s = \texttt{ACTCT}$ are $srl_1(s, 0) = 0$ and $srl_1(s, 1) = 2$.

For clearer discussion, we also define the \emph{skip-$c$-repeat} $sr_c(s,i)$ at position $i$ by dividing by $c + 1$:
\[sr_c(s,i) = srl_c(s, i)\ / (c + 1)\]
E.g., since $srl_1(\texttt{ACTCT}, 1) = 2$, \texttt{CT} is repeated once at position 1, i.e. $sr_1(\texttt{ACTCT}, 1) = 1$.

We then determine the \emph{next position} $np_c(s,l)$ of the $l$-th skip-$c$-repeat in $s$ with $|s| \geq 1$: 
\[
    np_c(s, l) = \begin{cases}
        1 & \text{for } l = 1\\
        np_c(s, l - 1) + srl_c(s, np_c(s, l - 1)) + 1 & \text{for } l > 1, np_c(s, l - 1)  < |s|
        \end{cases}
  \]
E.g. for $s = \texttt{ACACTC}$ we get $np_1(s, 1) = 1$ and $np_1(s, 2) = 4$.

%Let $F(h)$ be the factors of an integer $h$. 
The dust function $d(s)$ sums over all skip-$c$-repeat lengths with $c = 0,\ldots, c_{\max}$ in $s$ transformed via a variant of the Fibonacci function with $fib(0) = 0, fib(1) = 1, fib(2) = 2$ and for $n > 2$: $fib(n) = fib(n - 1) + fib(n - 2)$:
\[d(s) = \sum_{c = 0}^{c_{\max}}  \sum_{l=1}^{np_c(s, l) \leq |s|} fib(srl_c(s,  np_c(s, l)) 
%- \sum_{b + 1\in F(c + 1)} sr_b(s,  np_c(s, l)\ div\ (c +1) / (b + 1))
) 
\]

The use of the Fibonacci function in $d$ accounts for point 3 from the above rationale.

 $d(s)$ is symmetrical: Let $s'=s_k \ldots s_1$ be the reverse of $s=s_1\ldots s_k$; then it follows from the definition of $srl$ that $srl_c(s, i) = srl_c(s', |s| - i - srl_c(s, i) + 1)$. Since $np_c(s, l)$ determines the positions of all skip-$c$-repeats, doing so in reverse order leads to the same skip-$c$-repeat lengths and so, $d(s) = d(s')$.

We don't use $sr$ but $srl$ in $d$ because otherwise, longer repeats would be underrepresented at higher $d$ values. E.g., for a $31$-mer the maximum skip-$2$-repeat is 9 but the maximum skip-$0$-repeat is 30. This means that with a threshold for $d(s)$ greater than $fib(9)$, no true triplet repeat would qualify anymore.
 
 $d(s)$ does not compensate for double counts, e.g. $sr_0(\texttt{AAAA}, 1) = 3$ but also $sr_1(\texttt{AAAA}, 1) = 1$. We consider this as legitimate since \texttt{AAAA} is indeed both a triple repeat of \texttt{A} and a single repeat of \texttt{AA}. Given some skip-$c$-repeat, all factors of $c + 1$ are boosted this way. 
 
 For an efficient implementation that considers no more but triplets, we set $c_{\max} = 2$.
 Although the functional specification of $d(s)$ from above may seem intricate, its computation is simple and  iterates just once over $s$. Listing \ref{dust_alg} presents a simple Java version that computes $d(s)$ for $c_{\max} = 2$. It confirms the desired complexity of $O(|s|)$.
 With regard to Genestrip, we implemented a streaming variant too with the qualities as describe in the rationale from above (not shown).
 \clearpage
 \begin{lstlisting}[frame=single, basicstyle=\footnotesize\ttfamily, language=Java, numbers=left, numberstyle=\tiny\color{black},caption= {Computation of $d(s)$ in Java with a simplistic representation of a string $s$.}, ,label={dust_alg}]
    // int fib[] = ... is assumed to be defined beforehand.
    public int d(byte[] s) {
        int d = 0, srl0 = 0, srl1 = 0, srl2 = 0; // skip-c-repeat lenghts
        int l1 = -1, l2 = -1, l3 = -1;           // previous elements of s
        for (int i = 0; i < s.length; i++) {
            if (s[i] == l1) srl0++;
            else {
                d += fib[srl0];
                srl0 = 0; }
            if (s[i] == l2) srl1++;
            else {
                d += fib[srl1];
                srl1 = 0; }
            if (s[i] == l3) srl2++;
            else {
                d += fib[srl2];
                srl2 = 0; }
            l3 = l2; l2 = l1; l1 = s[i];
        }
        d += fib[srl0] + fib[srl1] + fib[srl2];
        return d;
    }
\end{lstlisting}
