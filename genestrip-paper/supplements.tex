    \section{Dust function $d$}\label{dust function}
We designed a simple dust function $d(s)$ that allows for recognizing a highly repetitive $k$-mer $s$ based on the following rationale:
\begin{itemize}
	\item Simple repeats like \texttt{TTTTTT}, repeating duplets like \texttt{ATATAT} and repeating triplets like \texttt{ATCATC} should be recognized.
	\item A repeat's contribution to $d$ should grow more than linearly with the repeat's length. E.g. \texttt{AAAAC} should return a larger $d$-value than \texttt{AACAA}. 
	\item $d(s)$ should be computable in $O(|s|)$ and should lend itself for streaming computation. I.e., if $d(s) = d(s_1 \ldots s_k)$ is known, then $d(s') = d(s_2 \ldots s_k s'_{k+1})$ should be computable in constant time.
	\item $d$ should ideally be symmetrical.
\end{itemize}

To specify the dust function $d$, we first define the \emph{skip-$c$-repeat length} at position $i$ in string $s$ where  $1 \leq i \leq |s|$:    
\[srl_c(s, i) = \max \{ r\ |\ i + r - 1 \leq |s| - c \wedge \bigwedge_{j = i}^{i + r - 1} s_j = s_{j + c} \}\]
E.g., two skip-$1$-repeats for $s = \texttt{ACTCT}$ are $srl_1(s, 0) = 0$ and $srl_1(s, 1) = 2$.

We obtain the \emph{skip-$c$-repeats} $sr_c(s,i)$ at position i by dividing by $c + 1$:

\[sr_c(s,i) = srl_c(s, i)\ div\ (c + 1)\]

We then determine the \emph{next position} $np_c(s,l)$ of the $l$-th skip-$c$-repeat in $s$ with $|s| \geq 1$: 
\[
    np_c(s, l) = \begin{cases}
        1 & \text{for } l = 1\\
        np_c(s, l - 1) + srl_c(s, np_c(s, l - 1)) + 1 & \text{for } l > 1, np_c(s, l - 1)  < |s|
        \end{cases}
  \]
E.g. for $s = \texttt{ACACTC}$ we get $np_1(s, 1) = 1$ and $np_1(s, 2) = 3$ and $np_1(s, 3) = 4$.

Let $F(h)$ be the factors of an integer $h$. The dust function $d(s)$ sums over all skip-$c$-repeats with $c = 0,\ldots, c_{\max}$ in $s$ weighted by the Fibonacci function $fib$ with $fib(0) = 0, fib(1) = 1, fib(n) = fib(n - 1) + fib(n - 2)$:

\[d(s) = \sum_{c = 0}^{c_{\max}}  \sum_{l=1}^{np_c(s, l) \leq |s|} fib(sr_c(s,  np_c(s, l)) - \sum_{b + 1\in F(c + 1)} sr_b(s,  np_c(s, l)\ div\ (c +1) / (b + 1))) \]
 
 The term \enquote{$- \sum_{b + 1\in F(c + 1)} \ldots$} ensures that double counting of repeats is avoided. E.g. $sr_0(\texttt{AAAA}, 1) = 3$ but also $sr_1(\texttt{AAAA}, 1) = 1}$.
