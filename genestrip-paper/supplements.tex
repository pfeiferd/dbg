    \section{The dust function $d$}\label{dust function}
We designed a simple dust function $d(s)$ that allows for recognizing and potentially excluding highly repetitive $k$-mers $s$ based on the following rationale:
\begin{enumerate}
	\item Simple repeats like \texttt{TTTTTT}, repeating pairs like \texttt{ATATAT} and repeating triplets like \texttt{ATCATC} should be recognized. (Triplets also form the basis of the approach in \cite{doi:10.1089/cmb.2006.13.1028}.)
	\item The function should be based on the number of times a single base, a pair or a triplet is repeated. E.g. \texttt{AT} is repeated twice in \texttt{ATATAT} and \texttt{ATC} is repeated once in \texttt{ATCATC}. 
	\item A repeat's contribution to $d$ should grow more than linearly with the repeat's length. E.g., \texttt{AAAACA} should obtain at least the $d$-value of \texttt{AACAAA} (or more). 
	\item $d$ should be symmetrical. This is because a $k$-mer and its reverse complement should obtain the same dust value \citep{doi:10.1089/cmb.2006.13.1028}.
	\item $d(s)$ should be computable in $O(|s|)$ and should lend itself for streaming computation. I.e., if $d(s) = d(s_1 \ldots s_k)$ is known, then $d(s') = d(s_2 \ldots s_k s'_{k+1})$ should be computable in constant time.
\end{enumerate}

To specify the dust function $d$, we first define the \emph{skip-$c$-repeat length} at position $i$ in a string $s$ where  $1 \leq i \leq |s|$ and $c \geq 0$:    
\[srl_c(s, i) = \max \{ r\ |\ i + r - 1 \leq |s| - c - 1 \wedge \bigwedge_{j = i}^{i + r - 1} s_j = s_{j + c + 1} \}\]
E.g., two skip-$1$-repeat lenghts for $s = \texttt{ACTCT}$ are $srl_1(s, 0) = 0$ and $srl_1(s, 1) = 2$.

We then determine the \emph{next position} $np_c(s,l)$ of the $l$-th skip-$c$-repeat length in $s$ with $|s| \geq 1$ as follows: 
\[
    np_c(s, l) = \begin{cases}
        1 & \text{for } l = 1\\
        np_c(s, l - 1) + srl_c(s, np_c(s, l - 1)) + 1 & \text{for } l > 1, np_c(s, l - 1)  < |s|
        \end{cases}
  \]
E.g. for $s = \texttt{ACACTC}$ we get $np_1(s, 1) = 1$ and $np_1(s, 2) = 4$.
For clearer discussion, we declare a \emph{skip-$c$-repeat} to be a substring of $s$ of length $srl_c(s,i)$ at a position $i$ \emph{as provided by $np_c$} (but not at any other positions).

%\[sr_c(s,i) = srl_c(s, i)\ / (c + 1)\]
%%E.g., since $srl_1(\texttt{ACTCT}, 1) = 2$, \texttt{CT} is repeated once at position 1, i.e. $sr_1(\texttt{ACTCT}, 1) = 1$.


%Let $F(h)$ be the factors of an integer $h$. 
The dust function $d(s)$ sums over the lengths of all skip-$c$-repeats in $s$ with $c = 0,\ldots, c_{\max}$ transformed via a variant of the Fibonacci function \citep{oeisA000045} where $fib(0) = 0, fib(1) = 1, fib(2) = 2$ and $fib(n) = fib(n - 1) + fib(n - 2)$ for $n > 2$:
\[d(s) = \sum_{c = 0}^{c_{\max}}  \sum_{l=1}^{np_c(s, l) \leq |s|} fib(srl_c(s,  np_c(s, l))) \]
The use of the Fibonacci function in $d$ accounts for point 3 from the above rationale.

 $d(s)$ is symmetrical: Let $s'=s_k \ldots s_1$ be the reverse of $s=s_1\ldots s_k$; then it follows from the definition of $srl_c$ that for a skip-$c$-repeat at position $i$ there is $srl_c(s, i) = srl_c(s', |s| - i - srl_c(s, i) + 1)$. Since $np_c(s, l)$ determines the positions of all skip-$c$-repeats, doing so in reverse order leads to the same skip-$c$-repeat lengths and so, $d(s) = d(s')$.

%We don't use $sr$ but $srl$ in $d$ because otherwise, repeats with a larger $c$ would become underrepresented at higher values of $d$. E.g., for a $31$-mer the maximum skip-$2$-repeat is 9 but the maximum skip-$0$-repeat is 30. This means that with a threshold $t$ for $d(s)$ and $d(s) \geq t \geq fib(9)$, no true skip-$2$-repeat (which is not a skip-$0$-repeat already) would qualify anymore.
 
 $d(s)$ does not compensate for double counts, e.g. $sr_0(\texttt{AAAA}, 1) = 3$ but also $sr_1(\texttt{AAAA}, 1) = 1$. We consider this as legitimate since \texttt{AAAA} is indeed both a skip-$0$-repeat of \texttt{A} and a skip-$1$-repeat of \texttt{AA}. In the general case, given some skip-$c$-repeat $h$ and a multiple $f + 1$ of $c + 1$ with $f \leq c_{\max}$: If $|h| > f$, then $h$ is also a skip-$f$-repeat. Therefore, $h$ gets ``boosted" in $d$ via any corresponding multiple $f + 1$.
 
 For an efficient implementation that considers no more but triplets, we set $c_{\max} = 2$.
 Although the functional specification of $d(s)$ from above may seem intricate, its computation is simple and iterates just once over $s$. Listing \ref{dust_alg} presents a basic Java implementation that computes $d(s)$ for $c_{\max} = 2$.\footnote{Although the presented algorithm works just for $c_{\max} = 2$, it can obviously be generalized for a larger $c_{\max}$ by introducing appropriate loops over $c = 0,\ldots,c_{\max}$.} It confirms the desired complexity of $O(|s|)$ given that $c_{\max}$ is constant.
 With regard to Genestrip, we implemented a streaming variant as well with the qualities as described in the rationale from above (not shown).

 \begin{lstlisting}[frame=single, basicstyle=\footnotesize\ttfamily, language=Java, numbers=left, numberstyle=\tiny\color{black},caption= {Computation of $d(s)$ for $c_{\max} = 2$ in Java with a simplistic representation of a string $s$.}, ,label={dust_alg}]
    // int fib[] = ... is assumed to be defined beforehand.
    public int d(byte[] s) {
        int d = 0, srl0 = 0, srl1 = 0, srl2 = 0; // skip-c-repeat lenghts
        int l1 = -1, l2 = -1, l3 = -1;           // previous elements of s
        for (int i = 0; i < s.length; i++) {
            if (s[i] == l1) srl0++;
            else {
                d += fib[srl0];
                srl0 = 0; }
            if (s[i] == l2) srl1++;
            else {
                d += fib[srl1];
                srl1 = 0; }
            if (s[i] == l3) srl2++;
            else {
                d += fib[srl2];
                srl2 = 0; }
            l3 = l2; l2 = l1; l1 = s[i];
        }
        d += fib[srl0] + fib[srl1] + fib[srl2];
        return d;
    }
\end{lstlisting}
